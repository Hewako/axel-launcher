# Релизный чек-лист Axel'

Проходить перед каждым тегом `vX.Y.Z`. Установщики собирает GitHub Actions (`release.yml`)
черновиком; публикует релиз владелец. Подписи сертификатом и автообновления нет (решение
владельца), на macOS — ad-hoc подпись пакета.

## До тега

- [ ] CI зелёный на macOS, Windows и Linux для коммита, который пойдёт в релиз
      (`cargo test`, clippy, fmt, `npm run build`, `npm run i18n:check`, `npm run ipc:check`).
- [ ] Версия одна во всех местах: `Cargo.toml` (workspace), `ui/package.json`.
- [ ] `CHANGELOG.md`: раздел «Ещё не вышло» переименован в `X.Y.Z — дата`, сверху новый пустой.
- [ ] Секреты репозитория на месте: `AXEL_MS_CLIENT_ID` (одобренный Mojang),
      `AXEL_CURSEFORGE_KEY` (если каталог CurseForge нужен в этой версии).
- [ ] Известные ограничения в README актуальны.
- [ ] Финальный аудит без находок уровня «исправить обязательно» (безопасность, утечка токенов).
- [ ] `cargo audit` — без уязвимостей; `npm audit --omit=dev` (в `ui/`) — без уязвимостей.
- [ ] Лицензии сторонних библиотек: `npm run licenses` (в `ui/`) обновил
  `ui/src-tauri/THIRD-PARTY-NOTICES.txt`; файл закоммичен и кладётся в установщики (`bundle.resources`).

## Пробная сборка (rc)

- [ ] Тег `vX.Y.Z-rc.N` → черновик релиза помечен pre-release (лаунчеры игроков его не видят).
- [ ] Собрались все три сборки (macOS универсальная, Windows, Linux) и задание `finalize`.
- [ ] В черновике ровно эти файлы: `Axel-Launcher-Windows.exe`, `Axel-Launcher-Windows-portable.zip`,
      `Axel-Launcher-macOS.dmg`, `Axel-Launcher-Linux.deb`, `Axel-Launcher-Linux.rpm`,
      `Axel-Launcher-Linux.AppImage`, `SHA256SUMS.txt` (лишние `finalize` удаляет сам).
- [ ] macOS: `lipo -archs` у `Axel Launcher.app/Contents/MacOS/axel-ui` → `x86_64 arm64`.
- [ ] macOS: `syspolicy_check distribution "Axel Launcher.app"` → только «Adhoc Signed App» и
      «Notary Ticket Missing» (оба — следствие выпуска без сертификата Apple), без «Codesign Error»
      (иначе скачанное из браузера приложение macOS назовёт повреждённым).
- [ ] macOS: приложение из `.dmg` запускается, открывается главная.
- [ ] Linux: зависимости `.deb` покрывают всё, что нужно программе
      (`llvm-objdump -p usr/bin/axel-ui | grep NEEDED` против `Depends`).
- [ ] Файлы проверены на VirusTotal (особенно `.exe` и `.zip`); ложные срабатывания — записать в релиз.
- [ ] Эталонный сценарий на чистой системе: установка → вход Microsoft → профиль Vanilla →
      запуск до главного меню → выход. macOS — Claude, Windows и Linux — владелец или ВМ
      (план v1.3, Gate 1→2).

## Проверка владельцем на Windows, Linux и Mac

Windows 10 или 11:
- [ ] Если стояла пробная версия через `.msi` — удалить в «Параметры → Приложения».
- [ ] Скачать `Axel-Launcher-Windows.exe`, запустить; SmartScreen — «Подробнее» → «Выполнить в любом случае».
- [ ] Окно языка: выбран язык системы, все страницы на выбранном языке.
- [ ] Папка по умолчанию в профиле пользователя, пароль администратора не спросили.
- [ ] Ярлыки на рабочем столе и в «Пуске»; галочка «Запустить Axel'» работает.
- [ ] Лаунчер открывается, вход Microsoft, профиль, игра до главного меню.
- [ ] Удаление: окно говорит про `%USERPROFILE%\.axel`; после удаления папка на месте.
- [ ] Установка поверх (тот же `.exe` ещё раз): окно про `.axel` не пугает, миры и профили на месте.
- [ ] Portable-zip: распаковать в любую папку, запустить `Axel Launcher.exe` — открывается.
- [ ] Картинки мастера: боковая полоса на первой и последней страницах, шапка на остальных и в окне удаления; ничего не размыто и не обрезано на масштабе 100 % и 150 %.

Linux:
- [ ] `.deb`: установка, значок в меню приложений, запуск.
- [ ] AppImage на Ubuntu: без `libfuse2` — что видно; с ним — запускается.
- [ ] Вход, профиль, игра до главного меню.

Mac (`.dmg` из черновика релиза):
- [ ] Окно образа: значок Axel' и «Программы» стоят на плашках (на CI позиции могут не примениться —
      tauri-apps/tauri#1731), подписи читаются в светлой и тёмной теме, нет белых полей, перетаскивание ставит приложение.

Лаунчер (при вышедшей новой версии):
- [ ] Лента внизу; «Скачать» открывает в браузере файл для своей системы, «Открыть страницу
      загрузки» — страницу релиза, «Позже» прячет ленту до перезапуска; в «Настройки → О Axel'»
      блок остаётся.

## Тег и публикация

- [ ] Тег `vX.Y.Z` на проверенном коммите `main` (тот же, что прошёл rc).
- [ ] Черновик собран, файлы и текст релиза проверены.
- [ ] Владелец публикует релиз. Проверка: в старой версии Axel' появилось «Вышла новая версия».
- [ ] Только для 0.1.0: в README вернуть прямые ссылки `releases/latest/download/<файл>` у кнопок «Скачать» и «Все файлы» (до выхода они ведут на страницу релизов).
- [ ] Постоянные ссылки из README (`releases/latest/download/…`) скачивают файлы этой версии;
      кнопка «Скачать» в старой версии Axel' скачивает файл для своей системы.

## Откат

Если после публикации нашлась ошибка, из-за которой игра не запускается или теряются данные:
1. Снять релиз с публикации (вернуть в черновик) — лаунчеры перестанут предлагать его.
2. Исправить, выпустить `vX.Y.Z+1` по этому же чек-листу.
Тег не переписывать: игроки могли уже скачать файлы этой версии.
