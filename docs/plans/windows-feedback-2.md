## Осталось — большие задачи

### 8. Отдельный экран «Каталог» (по образцу 16Launcher) — сделано 25.11.2026

Датапаки остались в окне на вкладке «Ресурсы»: они ставятся в конкретный мир.

16Launcher — закрытый проект без лицензии (репозитории `16steyy` на GitHub — только новости и
пустые заметки к релизам), поэтому код оттуда не берём, только идеи со скриншотов владельца.

- Кнопка «Каталог» на рельсе слева, экран на всю ширину.
- Сверху: источник (Modrinth / CurseForge), вид (Моды / Ресурспаки / Шейдеры / Сборки), справа
  пилюля «Версия 26.3 · Fabric · Сменить» — для какого профиля ставим; по умолчанию выбранный
  профиль, «Сменить» открывает выбор профиля (версия и загрузчик берутся из него).
- Поиск, переключатель «список / плитка».
- Слева фильтры: сортировка (загрузки, новые, обновлённые), «Клиент» и «Сервер» (любой,
  обязательно, опционально, нет), «Только установленные», категории.
- Карточка: значок, название, автор, описание, скачивания; если уже стоит — «Установлено».
- Внизу страницы «Назад / Вперёд» и номер страницы.
- Установка — та же фоновая очередь, что сейчас в окне каталога; окно каталога в профиле
  заменяется переходом на этот экран с уже выбранным профилем.
- Ядро: у поиска Modrinth уже есть offset и категории; нужно добавить сортировку и фильтр
  клиента и сервера (facets `client_side`, `server_side`) и признак «установлен».

### 4. Смена папки данных — сделано 25.11.2026

Указатель — `data-dir.txt` (`core/src/relocate.rs`). Непустая чужая папка → данные в папку «Axel» внутри.
После переноса полные пути в `launcher.toml` и `instance.toml` переписываются на новую папку.

- В «Настройки → Общие» и на шаге «Папка» мастера — кнопка «Выбрать другую папку…».
- Где лежит папка, хранится в маленьком файле в системной папке настроек
  (`%APPDATA%\Axel` / `~/Library/Application Support/Axel` / `~/.config/axel`);
  `~/.quarry` остаётся по умолчанию.
- При смене — перенос существующих данных с прогрессом (или «начать с пустой папки»),
  проверка места на диске, перезапуск лаунчера. Пока идёт игра — нельзя.

### 2. Игра с друзьями через интернет («комната»)

Minecraft сам умеет «Открыть для сети», но только в одной локальной сети. Чтобы друг из другого
города подключился к миру, нужен посредник в интернете — решение владельца, см. вопрос ниже.
Прогресс сохраняется как обычно: мир лежит у того, кто открыл комнату.

Варианты:
1. **Мод e4mc** (открытый, MIT): ставим его в профиль, «Открыть для сети» даёт адрес вида
   `xxx.e4mc.link`, друг вводит его в «Сетевой игре». Посредник — бесплатный сервер автора
   e4mc. Работает только в профилях с загрузчиком (Fabric, Quilt, Forge, NeoForge).
2. **playit.gg**: отдельная программа и аккаунт playit; работает и без модов, но это ещё
   один сервис и регистрация.
3. **Свой сервер-посредник Axel'**: полный контроль, но нужен сервер с оплатой, поддержка и
   политика приватности под него.

Рекомендация — вариант 1: без своих серверов и регистраций, открытый код, адрес копируется
одной кнопкой. Для профилей без модов — подсказка добавить загрузчик или «Открыть для сети»
в одной сети.
