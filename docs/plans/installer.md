# План: установщики Axel' «для людей»

Цель: игрок открывает страницу релиза или README, видит понятную ссылку для своей системы,
скачивает один файл и ставит его привычным способом, на своём языке. Ничего не компилирует,
не выбирает между архитектурами и не разбирается в `.app.tar.gz`.

Сейчас (rc.4): 9 файлов с техническими именами, два `.dmg` (Apple Silicon / Intel), установщик
Windows на английском, стандартное серое окно `.dmg`, в описании релиза нет таблицы «какой файл».

Без сертификатов разработчика (решение владельца 21.10.2026) остаются предупреждения
Windows SmartScreen и macOS Gatekeeper — их не убрать, только понятно объяснить.

## Решения владельца (21.11.2026)

| # | Решение | Почему |
|---|---|---|
| Р1 | macOS — один универсальный `.dmg` (Apple Silicon + Intel в одном приложении) | не нужно знать, какой у тебя процессор; цена — файл примерно вдвое больше (~20 МБ) |
| Р2 | Windows — только установщик `.exe` (NSIS), `.msi` не выкладываем | `.msi` нужен администраторам для массовой установки; игроку — лишний выбор |
| Р3 | Не выкладываем `.app.tar.gz` | это файлы для автообновления, которого у нас нет |
| Р4 | Имена файлов без версии: `Axel-Launcher-Windows.exe`, `Axel-Launcher-macOS.dmg`, `Axel-Launcher-Linux.deb`, `.rpm`, `.AppImage` | на них работают постоянные ссылки `releases/latest/download/…`: «Скачать» из README всегда даёт свежую версию |
| Р5 | Windows — установка для текущего пользователя, без прав администратора; ярлыки на рабочем столе и в «Пуске» | как у игровых лаунчеров, без пароля администратора |
| Р6 | Удаление программы не трогает миры и профили (`~/.quarry`) | миры игрока важнее чистоты диска; в окне удаления сказано, где лежат данные и как их убрать вручную |
| Р7 | Установщик Windows на русском и английском, язык выбирается в первом окне (по умолчанию — язык системы) | |
| Р8 | Картинки установщиков рисует владелец по техзаданию ниже; Claude подключает их и проверяет | |

## Как это работает для игрока

### Где скачать

- **README**, в самом верху: «Скачать Axel'» и три ссылки — Windows, macOS, Linux. Каждая ведёт
  на `https://github.com/Hewako/quarry-launcher/releases/latest/download/<файл>` и сразу
  скачивает файл последней опубликованной версии (не пробной).
- **Страница релиза**: таблица «Ваша система → какой файл», ниже — что делать, если система
  предупредила, и ссылка на подробную установку в README.

| Система | Файл |
|---|---|
| Windows 10 и 11 (64 бита) | `Axel-Launcher-Windows.exe` |
| macOS 11 и новее, любой Mac | `Axel-Launcher-macOS.dmg` |
| Ubuntu, Debian, Mint | `Axel-Launcher-Linux.deb` |
| Fedora, openSUSE | `Axel-Launcher-Linux.rpm` |
| Любой другой Linux | `Axel-Launcher-Linux.AppImage` |

### Windows

1. Игрок запускает `Axel-Launcher-Windows.exe`. Если Windows покажет «Система Windows защитила
   ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (нет сертификата; так и написано
   в релизе и README).
2. **Окно языка**: русский / English, выбран язык системы.
3. **Приветствие** (слева боковая картинка): что ставится, куда (папка пользователя), что права
   администратора не нужны, что миры и профили хранятся отдельно и не пропадут при удалении.
4. **Папка установки**: по умолчанию `%LOCALAPPDATA%\Axel Launcher`, можно сменить.
5. **Установка** с полосой прогресса. Если в системе нет WebView2 (бывает на старой Windows 10),
   установщик скачает его сам — нужен интернет.
6. **Готово** (снова боковая картинка): галочка «Запустить Axel'». Ярлыки — на рабочем столе и
   в меню «Пуск».
7. **Обновление**: игрок скачивает новый `.exe` и запускает поверх — старая версия заменяется,
   профили и миры на месте.
8. **Удаление**: «Параметры → Приложения» или ярлык удаления. Программа удаляется; миры,
   профили и настройки в папке `%USERPROFILE%\.quarry` остаются — об этом сказано в окне
   удаления, там же путь, чтобы удалить вручную. Галочка Tauri «Удалить данные приложения»
   стирает только служебные данные окна (например, положение узлов графа), не миры.

### macOS

1. Игрок открывает `Axel-Launcher-macOS.dmg` — появляется окно образа: слева значок Axel',
   справа ярлык «Программы», подсказка «Перетащите Axel' в «Программы»».
2. Перетаскивает, закрывает окно, извлекает образ.
3. Первый запуск: macOS скажет, что не может проверить приложение (нет сертификата). macOS 15 и
   новее — «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»;
   macOS 14 и старше — правый клик по приложению → «Открыть». Это один раз.
4. **Обновление**: тот же путь, при перетаскивании — «Заменить». Профили и миры в `~/.quarry`
   на месте.
5. **Удаление**: перетащить Axel Launcher из «Программ» в Корзину; данные в `~/.quarry`
   остаются (как написано в README).

### Linux

- `.deb`: двойной клик (откроется «Центр приложений») или `sudo apt install ./Axel-Launcher-Linux.deb`.
  Появляется в меню приложений со значком. Обновление — так же, новым файлом. Удаление — через
  «Центр приложений» или `sudo apt remove axel-launcher`.
- `.rpm`: `sudo dnf install ./Axel-Launcher-Linux.rpm`.
- `.AppImage`: «Свойства → Разрешить запуск как программу» (или `chmod +x`), затем двойной клик.
  Ничего не ставится в систему; в меню приложений сам не появляется.
- Данные — в `~/.quarry`, удаление программы их не трогает.

## Техзадание на дизайн (рисует владелец)

Общее: тёмная мята лаунчера — фон `#0b1110`, панели `#121b19`, мята `#52d6a0`, текст `#eaf2ed`,
второй текст `#a2b5ac`, главная кнопка янтарная `#f2bd4e`; шрифт IBM Plex Sans; значок-аксолотль
(`ui/src-tauri/icons/icon.png`). В лаунчере нет градиентов и теней — лучше держаться того же.
Текст на картинках ни Windows, ни macOS под язык не меняют: если на картинке есть надпись,
лучше по-русски и строкой ниже по-английски, или вовсе без текста.

| # | Файл (куда положить) | Размер и формат | Где показывается | Что учесть |
|---|---|---|---|---|
| Д1 | `ui/src-tauri/installer/dmg-background.png` | 660 × 400 px, PNG | фон окна `.dmg` на Mac | поверх картинки Finder сам рисует два значка: Axel' с центром в точке (180, 170) и «Программы» с центром в (480, 170), каждый около 128 × 128 и подпись под ним — в этих местах фон должен быть спокойным; стрелку/подсказку рисуете вы. Координаты можно сдвинуть — скажите, какие нужны |
| Д2 | `ui/src-tauri/installer/dmg-background@2x.png` | 1320 × 800 px, PNG | то же на экранах Retina | та же картинка вдвое крупнее (для чёткости) |
| Д3 | `ui/src-tauri/installer/nsis-sidebar.bmp` | 164 × 314 px, **BMP 24 бита** (не PNG) | левая полоса на первой и последней страницах установщика Windows | справа от неё Windows пишет текст на белом/светлом фоне окна; текста на самой картинке лучше немного или нет |
| Д4 | `ui/src-tauri/installer/nsis-header.bmp` | 150 × 57 px, **BMP 24 бита** | правый верхний угол на остальных страницах установщика | слева от неё — заголовок страницы на светлом фоне; обычно здесь только значок |
| Д5 | (необязательно) `ui/src-tauri/installer/volume.icns` | `.icns` | значок подключённого образа на рабочем столе Mac | если не будет — возьмём значок лаунчера |

Значок самого установщика Windows (`.exe`) и программы — уже есть (`icons/icon.ico`), рисовать не
нужно. Если картинок Д1–Д4 ещё нет, всё остальное работает: окно `.dmg` будет без фона, мастер
Windows — со стандартными картинками.

## Чего не делаем

- Подпись сертификатами Apple и Microsoft, нотаризация — решение владельца (нет сертификатов).
- Автообновление — решение владельца; лаунчер сообщает о версии и открывает страницу релиза.
- Свой сайт со скачиванием — хватает GitHub.
- Портативная версия Windows (zip без установки) — по запросу.

## Риски и что проверить

- `assetNamePattern` в tauri-action — сверить с документацией до правки.
- Универсальная сборка macOS требует обе цели Rust (`aarch64`, `x86_64`) и собирается дольше.
- Постоянные ссылки `releases/latest/download/…` не видят pre-release: работают только после
  публикации 0.1.0.
- Создаёт ли NSIS-шаблон Tauri ярлык на рабочем столе сам или только по галочке, и как именно
  выглядят его окна на русском — проверить на rc.5 (Windows — владелец).
- Картинки NSIS должны быть BMP 24 бита, иначе сборка Windows упадёт — проверится в CI.
