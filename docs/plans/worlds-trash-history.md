# Миры вне сборки, корзина и история сборок (решения владельца 26.11.2026)

## Решения

| # | Вопрос | Решение |
|---|---|---|
| 1 | Что запоминать | Рецепт: версия игры и загрузчика, моды/шейдеры/ресурспаки с источником и точной версией, config, options.txt, настройки запуска; файлы без источника — копией |
| 2 | Когда записывать | При каждом изменении; в интерфейсе — интерактивная карта: наведение или нажатие на дату показывает, что изменилось |
| 3 | Сколько хранить историю | Вечно |
| 4 | Срок в корзине | Настраивается в «Настройках»: от 24 часов до 60 дней, по умолчанию 30 дней; потом папка удаляется, рецепт остаётся |
| 5 | Удалить навсегда | Стирает папку, рецепт остаётся. Кнопка появляется только после «Удалить», так, чтобы не нажать случайно |
| 6 | Где в интерфейсе | Вкладка «Сборки»: фильтры «Корзина» и «История» |
| 7 | Мод исчез с Modrinth/CurseForge | Вернуть без него и написать, чего не хватило |
| 8 | Чьи миры | Мир хранится вне сборки и помнит свою сборку; в другой сборке той же линейки — кнопкой «Перенести сюда» с предупреждением о модах |
| 9 | Версии | Линейка: 1.16.x вместе (26.3.x вместе) |
| 10 | Мир старой линейки | Кнопка «Бэкап и перенести» (1.12.2 → 1.16.5); миры новее — не показываются |
| 11 | Уже существующие миры | Автоперенос, без поломок |
| 12 | Одинаковые имена | Переименовать: «Новый мир (Технология+)» |
| 13 | Что ещё вынести | Скриншоты — в общую папку по сборкам; servers.dat — общий для линейки; ресурспаки и шейдеры — в сборке (они в рецепте) |
| 14 | Сборки в папке официального лаунчера | Не трогать |
| 15 | Где на диске | В папке данных: `worlds/`, `screenshots/`, `servers/`, `history/`, `trash/` |

## Как устроено

**Миры.** `<данные>/worlds/<id сборки>/` — настоящие папки миров. `game/saves` у сборки — ссылка
туда (symlink; на Windows — junction, без прав администратора). Игра создаёт новые миры сразу в
хранилище. `worlds::ensure_store` при старте лаунчера, перед запуском и после создания/импорта:
- `saves` — ссылка на своё хранилище → ничего;
- ссылка не туда (перенос папки данных, старое `~/.quarry`) → пересоздать;
- настоящая папка → переименовать в хранилище (тот же диск) и поставить ссылку; если в хранилище
  уже есть миры — переложить по одному, одинаковые имена с суффиксом «(сборка)»;
- ссылку поставить не вышло → вернуть папку на место (работает как раньше).
Сборки с `external_game_dir` (папка официального лаунчера, перенос на другой диск) не трогаются;
перенос папки игры наружу сначала копирует миры из хранилища.

**Корзина.** `trash/<id>-<время>/` — папка сборки без миров (там только ссылка). Вернуть —
переименовать обратно (id занят → новый id), ссылка пересоздаётся. Срок — `trash_days`.

**История.** `history/<id>/<время>.toml` — рецепт; `history/blobs/<sha1>` — файлы без источника
и конфиги (по содержимому, без повторов). Новая запись — только если рецепт изменился.

## Порядок

1. Миры вне сборки + автоперенос. 2. Перенос миров между сборками, бэкап старых.
3. Скриншоты и servers.dat. 4. Корзина. 5. История: запись. 6. История: карта и возврат.
