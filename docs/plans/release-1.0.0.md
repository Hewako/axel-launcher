# План выпуска Axel' 1.0.0-d и следующих версий

Составлен 27.11.2026 по ревизии (готовность к релизу, интерфейс навыком ui-audit) и выбору идей
владельцем. Нумерация идей — как в переписке (1–65). Решения владельца:

- 1.0.0-d — ревизия, исправления интерфейса и самые нужные идеи; остальное — следующими версиями
  **1.0.1** (мелкие правки) или **1.1.0, 1.2.0…** (крупные), каждая сначала сборкой разработчика
  `vX.Y.Z-d` (черновик, оформлен как обычный релиз).
- Обмен модами — без своего сервера, только внутри комнаты; комната закреплена: после перезапуска
  у хозяина тот же код, гость переподключается сам.
- OptiFine — игроки ставят сами: его лицензия запрещает выкладывать файл где-либо ещё и скачивать
  в обход optifine.net. Axel' открывает официальную страницу, сам подхватывает скачанный файл из
  «Загрузок» и ставит правильно (без загрузчика — отдельной версией, с Forge — как мод); рядом
  подсказка про Sodium и Iris.
- Подпись: SignPath — заявку подаёт владелец; автообновление — на ключе Tauri.
- winget, Homebrew, Flathub — заготовки делает Claude, отправляет по данным владельца.
- Бэкап «в облако» — в любую папку (папка Яндекс Диска, iCloud, Google Drive на компьютере).
- Skin Studio — для Microsoft и Ely.by (скины Ely.by берутся оттуда).
- Новости — из списка версий Mojang и обновлений установленных модов (Modrinth, CurseForge).
- Карта мира — только где игрок был (из файлов мира), без генерации по сиду.
- При первом запуске — тур по экранам.
- Для работы — навыки плагина my-toolkit (interface-design, ui-audit, plan-and-build, testing,
  debugging, code-review, ux-writing) по необходимости.

Каждый пункт считается сделанным, только когда: код + тест (для ядра), проверка в превью или
вживую, CI зелёный на трёх ОС, запись в CHANGELOG.
